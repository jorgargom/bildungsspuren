2. Alojamiento y datos del servidor

Esta web se publica mediante GitHub Pages. Cuando accedes, GitHub trata datos técnicos de conexión, como la dirección IP, fecha y hora, URL solicitada e información del navegador y del dispositivo. La finalidad es servir la web y mantener su estabilidad y seguridad. La base jurídica que aplica el responsable de la web es el art. 6.1.f RGPD: el interés legítimo en mantener un sitio seguro y operativo. El destinatario es GitHub. Los datos se conservan durante el tiempo necesario para la seguridad y el funcionamiento, conforme a las reglas del proveedor; el titular de la web no controla sus plazos internos de borrado. Consulta la política de privacidad de GitHub. GitHub almacena y trata datos personales en distintas ubicaciones, incluidos Estados Unidos y otros países. Para las transferencias desde el EEE, GitHub indica que utiliza el EU-US Data Privacy Framework cuando corresponde y las cláusulas contractuales tipo de la Comisión Europea para otras transferencias sujetas a garantías.

3. Contacto por correo electrónico

Si escribes a kontakt@bildungsspuren.de, se tratan los datos que incluyas, como tu dirección de correo, el contenido del mensaje y los archivos adjuntos, para gestionar y responder a tu consulta. El correo se reenvía mediante Porkbun y se recibe en Proton Mail. La base jurídica es el art. 6.1.f RGPD: el interés legítimo en responder a los mensajes que recibimos voluntariamente y gestionar la comunicación. Los datos se eliminan cuando la consulta queda resuelta y ya no es necesario conservarlos para aclaraciones o defensa de posibles reclamaciones. Se mantienen los plazos legales de conservación que pudieran aplicarse. Los destinatarios son Porkbun y Proton. Consulta sus políticas de privacidad y la política de Proton Mail.

4. Contenidos externos, cookies y analítica

Según la configuración actual, la web no integra fuentes externas, mapas, vídeos, contenidos de redes sociales ni herramientas de analítica. No utiliza cookies de análisis o publicidad ni mide la audiencia. Tampoco tiene formulario de contacto. Los enlaces externos, por ejemplo a Instagram, solo conectan con esos proveedores cuando haces clic.

5. Destinatarios y transferencias internacionales

Los destinatarios son GitHub como proveedor de alojamiento y Porkbun y Proton para el reenvío y la recepción del correo. GitHub también trata datos en Estados Unidos y otros países. GitHub indica que utiliza, entre otros mecanismos, el Marco de Privacidad de Datos UE-EE. UU. (DPF) y las cláusulas contractuales tipo (SCC) para transferencias de datos personales desde el Espacio Económico Europeo. Porkbun LLC tiene su sede en Estados Unidos. Su anexo de tratamiento de datos contempla cláusulas contractuales tipo de la UE para datos del EEE que se transfieran a través de sus servicios a países sin una decisión de adecuación, siempre que esa disposición sea aplicable al contrato concreto. Proton AG tiene su sede en Suiza, país para el que la Comisión Europea ha reconocido un nivel adecuado de protección. Los lugares reales de tratamiento y las posibles transferencias posteriores también dependen de los subencargados de cada proveedor. Más información: GitHub, anexo de tratamiento de datos de Porkbun, Proton Mail y decisiones de adecuación de la Comisión Europea.

6. Tus derechos

Conforme al RGPD, puedes solicitar acceso, rectificación, supresión, limitación del tratamiento y portabilidad. Si el tratamiento se basa en el art. 6.1.f RGPD, puedes oponerte por motivos relacionados con tu situación particular. También puedes reclamar ante una autoridad de protección de datos. La autoridad competente en Bremen es el Landesbeauftragter für Datenschutz und Informationsfreiheit Bremen, Georgstraße 122–124, 27570 Bremerhaven, correo: office@datenschutz.bremen.de.

7. Datos obligatorios y decisiones automatizadas

Los datos técnicos de conexión son necesarios para acceder a la web. Cuando envías un correo, decides qué información facilitas; si faltan datos suficientes, quizá no podamos responder. No se toman decisiones automatizadas ni se elaboran perfiles.

8. Actualización

Última actualización: 17 de noviembre de 2026. Esta política describe la configuración conocida actualmente y se actualizará si cambian el alojamiento, el correo, los servicios integrados o las funciones de la web.
