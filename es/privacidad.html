Alojamiento

Esta web está alojada en GitHub Pages. Al visitarla pueden tratarse datos técnicos como la dirección IP, la hora de acceso, la página solicitada y datos del navegador o sistema operativo para servir y proteger la web. Consulta la política de privacidad de GitHub.

Contacto por correo

Los mensajes enviados a kontakt@bildungsspuren.de se reenvían mediante Porkbun y se reciben en un buzón de Proton Mail. El contenido y los datos de contacto se tratan para responder a tu consulta.

Enlaces externos

Esta web no integra tipografías externas, herramientas de analítica ni contenidos de redes sociales. El enlace a Instagram lleva a un servicio externo, cuya política de privacidad se aplica cuando accedes.

Cookies y analítica

Según la configuración actual, esta web no utiliza cookies de análisis o publicidad ni herramientas de medición de audiencia. No hay formulario de contacto.

Tus derechos

Cuando la normativa lo permita, puedes ejercer tus derechos de acceso, rectificación, supresión, limitación, oposición y portabilidad, así como reclamar ante una autoridad de protección de datos.

Actualización

Última actualización: 17 de noviembre de 2026. Este texto se revisará si cambian la web o los servicios utilizados.
